Enrol

Run this once. It creates the key that encrypts the dashboard, binds a passkey to it, and binds a recovery passphrase to it as well. Running it again makes a new key and orphans every report already published, so do not run it twice without meaning to.

  1. Choose a recovery passphrase. Long, and stored somewhere you will still have it in a year. It is the only route back in if the passkey is ever lost, and there is no server that can reset it.
  2. Enrol. Your phone or laptop will ask for Face ID or a fingerprint.
  3. Commit the generated keys.json and put the data key in the repository secrets. Both are shown at the end.
